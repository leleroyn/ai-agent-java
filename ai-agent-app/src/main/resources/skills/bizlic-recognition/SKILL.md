# 营业执照识别

## 怎么调（照抄模板，只填文件路径）

用 shell 工具执行（`execute_shell_command`），一条命令一个文件。**整条命令照抄下面这一行，只把 `src/<文件名>` 换成实际路径，其它字符一个都不改**：

```
ips bizlic src/<文件名> | python3 -c "print(__import__('json').loads(__import__('sys').stdin.read().strip() or '[{}]')[0].get('ocr_text') or 'not_detected')"
```

这条模板做两件事：调营业执照接口，再把返回里 `ocr_text` 那层 JSON 字符串解开，直接吐字段对象。

- **禁止自己写解析**：不要把上一条命令的 JSON 输出粘进新命令的源码里再解析一遍，也不要为了「整理/格式化 JSON」再起一条 python。粘过去要穿 4 层转义（bash 双引号 / 字符串字面量 / JSON / 接口原文），实测会炸，信用代码、注册资本数字、长住所还会漏抄；那几百个字符还全算进生成量。路径之外，模板里没有任何需要改的东西。
- 模板输出是**一行合法 JSON 字段对象**，key 就是接口口径名（不要改名）：`社会统一信用代码`、`企业名称`、`类型`、`法定代表人`、`注册资本`、`成立日期`、`营业期限`、`住所`、`经营范围`。**拿到这行就够作答了**，字段值原样抄进结果。
- 读不到的字段是**空字符串**——按缺失处理（写 null）。`经营范围` 为空串属正常（很多版面读不全），不要凭企业名称编造。
- 字段值一律取接口原文：**不要按位数「修正」信用代码、不要重写注册资本的数字**（`173443.17万元` 与 `17344.17万元` 是不同结果，`贰仟万元整` 不要改成 `2000万元`），不做四舍五入或补零。
- 来源只能是本任务目录内的本地路径，**只支持图片（PNG/JPG/JPEG）**。指令里点名的文件已在 `src/` 下，把路径原样填进模板即可。
- **PDF 不支持**：营业执照检测接口只收图片。来源是 PDF 时不要调这条命令，改用 `extract_document_fields` 从 PDF 里取字段，并在结果里说明用的是通用抽取、不是证照专用通道。
- **禁止先下载**：不要 `curl`/`wget`（已被禁用），不要把指令里的 URL 当参数传。
- 多个文件逐条执行，命令一次只吃一个文件；同一文件不要调第二次（服务端有缓存，结论不会变）。
- 可选参数加在 `ips bizlic` 后面：`--init-confidence 0.9`（默认 0.8）、`--timeout 60`（秒）。默认值够用，别默认改阈值。
- `bizlic_type` 恒为 `1`，表示「营业执照」这一证照类别，**不是版本或类型编号**，不要据此判证照种类；`corp_image_base64` 恒为 null，忽略，不要放进结果。

常见说法到接口字段的对照：

| 任务里的说法 | 接口字段 |
| --- | --- |
| 统一社会信用代码 / 信用代码 / 工商号 | `社会统一信用代码` |
| 公司名称 / 单位名称 / 抬头 | `企业名称` |
| 法人 / 负责人 / 经营者 | `法定代表人` |
| 注册资金 / 出资额 | `注册资本` |
| 注册日期 / 发证日期 | `成立日期` |
| 地址 | `住所` |

## 输出 `not_detected` 也是结论

模板打印 `not_detected`（退出码 `0`，stderr 同时有 `错误: API 错误: HTTP 400 未检测到有效营业执照.`）表示**这张图里没有可识别的营业执照**——身份证、发票、开户许可证、登记证书、截图都会这样返回。这不是格式错误也不是失败，是权威终局结论：

- 不得改用 `extract_document_fields` 或 `understand_document` 去「补」营业执照字段，也不要调阈值重试。
- 只有当任务要的是**其它证照/单据**的通用字段时，才改用 `extract_document_fields`，并在结果里说明它不是营业执照通道给出的结论。

## 管道被白名单拒时（只允许 `ips` 的部署）

运维把 `AGENT_SHELL_ALLOWED` 设成只有 `ips` 时，第二段 `python3` 会被逐段白名单拒掉（模型收到 `SecurityError`，命令不执行）。**收到 `SecurityError` ＝ `python3` 整体不在白名单里：不要再换解析写法重试**，换 `python`/`jq`/`head`、换成 heredoc、换成短键名，只会拿到同一条拒绝。直接去掉管道，只跑：

```
ips bizlic src/<文件名>
```

stdout 是**恰好 1 个元素**的数组：`[{"confidence": 1.0, "bizlic_type": 1, "ocr_text": "{...}", "corp_image_base64": null}]`。**直接读**里面 `ocr_text` 那个 JSON 字符串取字段（key 同上）——不要为解析再起一条 shell。这种跑法下退出码 `0` 才是识别成功；stdout 为空 + 退出码 `1` + stderr「未检测到有效营业执照.」＝上面那条「不是营业执照」。

## 其它退出码

- `1` 且 stderr 是「文件不存在」等中文原因：原样转述，最多重试一次。
- `3`：`bizlic` 子命令未开放（`IPS_ALLOWED_SUBCOMMANDS` 没放行）。直接说明无法识别，不要换别的命令绕过去。
- 不要用 `ips ocr` 读证照图片的原文——默认未开放，且会把无关全文灌进上下文。
