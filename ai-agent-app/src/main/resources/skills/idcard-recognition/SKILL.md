# 身份证识别

## 怎么调（照抄模板，只填文件路径）

用 shell 工具执行（`execute_shell_command`），一条命令一个文件。**整条命令照抄下面这一行，只把 `src/<文件名>` 换成实际路径，其它字符一个都不改**：

```
ips idcard src/<文件名> | python3 -c "print(__import__('json').loads(__import__('sys').stdin.read().strip() or '[{}]')[0].get('ocr_text') or 'not_detected')"
```

这条模板做两件事：调身份证接口，再把返回里 `ocr_text` 那层 JSON 字符串解开，直接吐字段对象。

- **禁止自己写解析**：不要把上一条命令的 JSON 输出粘进新命令的源码里再解析一遍。粘过去要穿 4 层转义（bash 双引号 / 字符串字面量 / JSON / 接口原文），实测会炸，长住址、18 位号码、末位 `X` 也会漏抄；那几百个字符还全算进生成量。路径之外，模板里没有任何需要改的东西。
- 模板输出是**一行字段对象**，key 就是接口口径名（不要改名）：`姓名`、`性别`、`民族`、`出生`、`住址`、`公民身份号码`、`签发机关`、`有效期限`。
- 读不到的字段是**空字符串**——按缺失处理（写 null），不要从另一面、上下文或常识补出来。
- 字段值一律取接口原文：姓名里的生僻字、住址里的门牌号、号码位数都不许「修正」或补全。`公民身份号码` 正常是 18 位（末位可能是大写 `X`），读成 17 位就写 17 位。
- 来源只能是本任务目录内的本地路径，**只支持图片（PNG/JPG/JPEG）**。指令里点名的文件已在 `src/` 下，把路径原样填进模板即可。
- **PDF 不支持**：身份证检测接口只收图片。来源是 PDF 时不要调这条命令，改用 `extract_document_fields` 从 PDF 里取字段，并在结果里说明用的是通用抽取、不是证件专用通道。
- **禁止先下载**：不要 `curl`/`wget`（已被禁用），不要把指令里的 URL 当参数传。
- 多个文件逐条执行，命令一次只吃一个文件；同一文件不要调第二次（服务端有缓存，结论不会变）。
- 可选参数加在 `ips idcard` 后面：`--init-confidence 0.6`（默认 0.5）、`--timeout 60`（秒）。默认值够用，别默认改阈值。

## 输出 `not_detected` 也是结论

模板打印 `not_detected`（退出码 `0`，stderr 同时有 `错误: API 错误: HTTP 400 未检测到有效身份证.`）表示**这张图里没有可识别的居民身份证**——护照、驾照、银行卡、空白页、只拍到证件背面都会这样返回。这不是格式错误也不是失败，是权威终局结论：

- 不得改用 `extract_document_fields` 或 `understand_document` 去「补」身份证字段，也不要调阈值重试。
- 只有当任务要的是**其它单据/其它证件**的通用字段时，才改用 `extract_document_fields`，并在结果里说明它不是身份证专用通道给出的结论。

## 管道被白名单拒时（只允许 `ips` 的部署）

运维把 `AGENT_SHELL_ALLOWED` 设成只有 `ips` 时，第二段 `python3` 会被逐段白名单拒掉（模型收到 `SecurityError`，命令不执行）。**收到 `SecurityError` ＝ `python3` 整体不在白名单里：不要再换解析写法重试**，换 `python`/`jq`/`head` 只会拿到同一条拒绝。直接去掉管道，只跑下面这条，拿到 stdout 就照着 `ocr_text` 作答：

```
ips idcard src/<文件名>
```

stdout 是**恰好 1 个元素**的数组：`[{"confidence": 0.97, "idcard_type": 1, "ocr_text": "{...}", "corp_image_base64": null}]`。**直接读**里面 `ocr_text` 那个 JSON 字符串取字段（key 同上）——不要为解析再起一条 shell，也不要自己写 python 粘数据。

- `idcard_type` 恒为 `1`，表示「身份证（按正面处理）」这一证件类别，**不是正反面编号**——检测模型不区分正反面，不要据此判正反。
- `confidence` 是检测置信度，判「是不是有效身份证」以退出码/stdout 为准，不要拿它当字段依据。
- `corp_image_base64` 恒为 null，忽略，不要放进结果。
- 这种跑法下退出码 `0` 才是识别成功；stdout 为空 + 退出码 `1` + stderr「未检测到有效身份证.」＝上面那条「不是身份证」。

## 其它退出码

- `1` 且 stderr 是「文件不存在」等中文原因：原样转述，最多重试一次。
- `3`：`idcard` 子命令未开放（`IPS_ALLOWED_SUBCOMMANDS` 没放行）。直接说明无法识别，不要换别的命令绕过去。
- 不要用 `ips ocr` 读证件图片的原文——默认未开放，且会把无关全文灌进上下文。
