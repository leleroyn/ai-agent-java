# 印章识别

## 怎么调

用 shell 工具执行（`execute_shell_command`），一条命令一个文件：

```
ips seal src/<文件名>
```

- 来源只能是本任务目录内的本地路径。指令里点名的文件已在 `src/` 下，把指令里的路径原样传进去即可。
- **禁止先下载**：不要 `curl`/`wget`（已被禁用），不要把指令里的 URL 当参数传——工具只吃本地路径。
- 多个文件就逐条执行，命令一次只吃一个文件。
- 可选参数：`--init-confidence 0.8`（提高检测阈值）、`--timeout 60`（秒）。默认值够用，别默认改阈值。
- 同一个文件不要调第二次：服务端有缓存，重复调用结论不会变，只是白烧一轮迭代。

## 返回口径

标准输出是 JSON 数组，一个印章一个对象：

| 键 | 含义 |
| --- | --- |
| `ocr_result` | 印章上的公司名称——要公司名就取这个 |
| `seal_type` | 1=圆形红色章，2=圆形灰色章 |
| `confidence` | 检测置信度 0~1 |
| `seal_image_base64` | 恒为空串，忽略，不要放进结果 |

- 空数组 `[]` = **未检出印章**。这就是权威终局结论：不得改用 `understand_document` 或 `extract_document_fields` 再找一遍，也不得调阈值重试。
- `ocr_result` 只读出局部字样（例如只读到「云南省」）属正常现象，以读到的原文为准，**不要改写、补全、或按上下文猜成"更完整"的公司名**。
- 退出码：`0` 成功；`1` 接口或文件错误，stderr 是中文原因（如「文件不存在」），原样转述即可，最多重试一次；`3` 表示 `seal` 子命令未开放（`IPS_ALLOWED_SUBCOMMANDS` 没放行），直接说明无法识别，不要换别的命令绕过去。

## 硬性禁止

- 不要用 `ips ocr` 读印章图片的原文——默认未开放，且会把无关全文灌进上下文。
- 不要用视觉/理解工具"看图找章"，专用接口的结果比视觉猜的准。
- 结果按来源逐条给出，建议形状：`{"source": "...", "has_seal": true, "seals": [{"company": "...", "seal_type": 1, "confidence": 0.95}]}`；没检出就 `has_seal=false`、`seals=[]`。
