# 工具与技能调用示例（主模型 pro）

面向下游调用的示例集，覆盖 5 个自定义工具与 2 个技能，每项含**简单**与**复杂**示例。
所有示例均已在测试环境用 `model:"pro"` 实跑通过（见文末「验证结果」）。

## 0. 通用说明

- **接口**：`POST /api/v1/agent/task`，请求体 `Content-Type: application/json`（UTF-8）。
- **模型**：本文件示例统一 `"model":"pro"`（大上下文，适合多工具/多页/多图）。简单短任务可用默认 `flash`。
  ⚠️ `flash`＝minicpm，`n_ctx=8192`，固定开销约 4700 token，复杂任务会上下文溢出——**复杂示例请用 pro**。
- **同步**：`options.sync=true` 时 HTTP 阻塞到任务结束；异步则轮询 `GET /api/v1/agent/task/{taskId}`。
- **超时**：`options.timeoutSeconds`。图片/PDF/多页任务耗时较长（实测 pro：单图约 60–100s、3 页 PDF 约 50–100s、3 图批量约 160s）。**多图/组合示例给到 300–420s**。
  ⚠️ 并发跑多个图片/PDF 任务会**争抢视觉端点**（`:8008` VL slots 少），单个任务耗时可能成倍上升甚至超时——批量提交请给足 `timeoutSeconds` 或错开提交（串行最稳）。
- **文件 URL**：必须用**容器可达的地址**（本环境为 `http://192.168.2.203:8090/...`，不要用 `localhost`——`localhost` 是容器自身，访问不到宿主机文件服务）。

## 1. `get_system_time`（系统时间）

### 1.1 简单——当前时间

```json
{
  "instruction": "现在是几点？请给出北京时间的日期和时间。",
  "model": "pro"
}
```

### 1.2 复杂——相对日期 + 结构化

```json
{
  "instruction": "今天是几号？计算并返回：今天、7 天后、30 天前、以及 3 小时后的时间。日期用 YYYY-MM-DD，时间用 YYYY-MM-DD HH:mm:ss。",
  "model": "pro",
  "outputSchema": {
    "$schema": "http://json-schema.org/draft-07/schema#",
    "type": "object",
    "properties": {
      "today": { "type": "string", "description": "今天，YYYY-MM-DD" },
      "plus_7_days": { "type": "string", "description": "7 天后，YYYY-MM-DD" },
      "minus_30_days": { "type": "string", "description": "30 天前，YYYY-MM-DD" },
      "plus_3_hours": { "type": "string", "description": "3 小时后，YYYY-MM-DD HH:mm:ss" }
    },
    "required": ["today", "plus_7_days", "minus_30_days", "plus_3_hours"]
  }
}
```

## 3. `extract_image_fields`（图片字段结构化抽取）

多张图会逐图并行抽取，返回与图片一一对应的记录。

### 3.1 简单——单图抽几个字段

```json
{
  "instruction": "从这张发票图里抽取：发票号码、开票日期、价税合计。\nhttp://192.168.2.203:8090/files/test/20260920/fcfacd61510d4203b3fd64a9bb43ac05.png",
  "model": "pro",
  "outputSchema": {
    "$schema": "http://json-schema.org/draft-07/schema#",
    "type": "object",
    "properties": {
      "invoice_number": { "type": ["string", "null"] },
      "invoice_date": { "type": ["string", "null"], "description": "YYYY-MM-DD" },
      "total_amount_with_tax": { "type": ["string", "null"], "description": "价税合计，去货币符号与千分位" }
    },
    "required": ["invoice_number", "invoice_date", "total_amount_with_tax"]
  }
}
```

### 3.2 复杂——多图批量、逐图记录

```json
{
  "instruction": "逐张抽取下面发票图中的：发票号码、发票代码、开票日期、购买方名称、销售方名称、价税合计。按输入顺序返回，每条记录带上对应的图片 URL。\nhttp://192.168.2.203:8090/files/test/20260920/fcfacd61510d4203b3fd64a9bb43ac05.png\nhttp://192.168.2.203:8090/files/test/20260920/16b73a4c81a94371a487bc93d25be429.png\nhttp://192.168.2.203:8090/files/test/20260920/29004dad238243b9a7ae7bce4d9da765.jpg",
  "model": "pro",
  "options": { "sync": true, "timeoutSeconds": 300 },
  "outputSchema": {
    "$schema": "http://json-schema.org/draft-07/schema#",
    "type": "object",
    "properties": {
      "invoices": {
        "type": "array",
        "items": {
          "type": "object",
          "properties": {
            "image_url": { "type": "string" },
            "invoice_number": { "type": ["string", "null"] },
            "invoice_code": { "type": ["string", "null"] },
            "invoice_date": { "type": ["string", "null"], "description": "YYYY-MM-DD" },
            "buyer_name": { "type": ["string", "null"] },
            "seller_name": { "type": ["string", "null"] },
            "total_amount_with_tax": { "type": ["string", "null"] }
          },
          "required": ["image_url", "invoice_number", "invoice_code", "invoice_date", "buyer_name", "seller_name", "total_amount_with_tax"]
```

```json
      "image_invoice_number": { "type": ["string", "null"] },
```

| # | 能力 | 用例 | 结果（耗时 / 关键结论） |
| :-- | :-- | :-- | :-- |
| 1.1 | get_system_time | 当前时间 | ✅ ~15s，北京时间正确 |
| 1.2 | get_system_time | 相对日期+schema | ✅ ~47s，今天/+7/−30/+3h 正确 |
| 2.1 | understand_image | 单图概览 | ✅ ~99s，识别为云南增值税专用发票、票面要素齐全 |
| 2.2 | understand_image | 多图对比 | ✅ ~126s，两印章主体不同（重庆冠华 vs 成都市青羊区行政审批局），判定不一致 |

| 3.2 | extract_image_fields | 多图批量(3) | ✅ ~163s（`timeout≥300`），3 条逐图记录全部正确 |
| 4.1 | understand_pdf | 文档概览 | ✅ ~47s，ACME Invoice、3 页 |
| 4.2 | understand_pdf | 跨页+溯源 | ✅ ~66s，字段+页码全对（INV-2026-0007 第1页、总额 88888.00 第2页…） |
